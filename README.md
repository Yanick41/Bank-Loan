 ## Bank Loan Analysis Dashboard

 ## Project Overview

The **Bank Loan Analysis Dashboard** is a Power BI project designed to analyze loan applications, funded amounts, repayments, customer profiles, and loan performance indicators.

This dashboard helps financial institutions **monitor lending activities**, **assess portfolio performance**, and **identify trends** that support strategic decision-making.

 ## Project Objectives

-  Analyze loan application trends
-  Monitor funded and received loan amounts
-  Evaluate borrower profiles
-  Track loan performance metrics
-  Identify patterns in loan approvals and repayments
-  Support data-driven banking decisions

##  Dashboard Features

###  Executive Summary
High-level overview of loan performance and key business metrics across the entire portfolio.

### Loan Overview
Visual trends, distributions, and performance indicators across the loan portfolio over time.

###  Detailed Analysis
Drill-down capabilities across multiple dimensions:

- Loan Purpose
- Home Ownership Status
- Loan Grade & Sub-Grade
- Funded Amount & Installments
- Amount Received
- Loan Issue Dates

---

## 🔍 Interactive Filters

Users can dynamically filter and explore data by:

- 📍 **State**
- 🏷 **Loan Grade**
- ✅ **Good vs Bad Loan Classification**

This enables flexible, segment-level exploration of loan performance.

---

## 💡 Business Insights

This dashboard empowers stakeholders to:

- Understand lending patterns across regions and segments
- Identify high-performing loan categories
- Monitor repayment performance over time
- Assess borrower risk profiles
- Improve and refine loan approval strategies
